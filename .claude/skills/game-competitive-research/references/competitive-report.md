# 竞品分析报告

## 选择规则

- 非对比状态默认选择顶部主游戏及当前历史版本。
- 对比状态默认选择对比篮的前两款游戏及各自最新版本。
- 报告页允许独立改选，但一份报告最多两款游戏，且不能重复选择同一款。
- 报告页的独立选择不改写知识库、顶部主游戏、历史版本或对比篮。

## 单产品报告

按执行摘要、产品总览、系统与玩法、空间与视觉表现、商业化活动、社区运营、关键观察、证据缺口和证据来源组织。流水、日活等经营指标只有在所选快照存在数据时才出现。“系统与玩法”中的核心循环、主要系统与视觉表现必须使用分组表单结构；HTML/PDF 预览将每一行渲染为有层级的卡片式信息块，不得退化为连续纯文本。

## 双产品报告

使用统一的“对比项 × 游戏”表格，依次覆盖产品总览、系统与玩法、商业化、社区运营和证据缺口。产品列必须稳定对齐，不得拆成逐项卡片。主要系统单元格必须逐系统分点，并在每个系统下区分目标、规则和依赖，避免多个系统串成无层级段落。覆盖日期不一致时，明确说明时点指标不可直接视为同期数据。

## 事实与证据

- 只使用所选知识快照中的事实、观察、推断标记与来源。
- 缺失值保留为“待收集”或“未获得可靠公开数据”，不得使用类型母版补成竞品事实。
- 每份报告保留来源标题、URL、发布方或来源类型及访问日期。
- 不输出安装路径、母版路径、内部版本哈希或开发包配置说明。

## 导出

- `MD`: 保留标题层级、表格、证据链接和数据版本说明。
- `PDF`: 通过右侧 HTML 预览打印，隐藏应用导航与设置栏，避免表格行跨页断裂。
- 右侧 HTML 只用于预览，不额外提供 HTML 文件下载。
