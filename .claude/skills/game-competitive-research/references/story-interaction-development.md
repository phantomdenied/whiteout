# 剧情互动类条件母版

当产品属于互动影游、视觉小说、剧情互动或叙事解谜，或至少两个已证实系统命中 S07/S08/S09/S16/S38/S42 时，读取 `story-development-template.json` 并生成剧情系统章节。原始参考工作簿保存在 `assets/story-interaction-development-template-v1.0.xlsx`，只用于审计表格结构。

输出剧情系统、年代时间线、章节场景、选择节点、结局反馈、分镜制作和原创策划的空白结构。仅把知识库中有证据支持的竞品系统写成事实；时间线、剧情、角色、台词、镜头、变量值和原创方案不得从参考产品复制。未触发条件时，不生成剧情章节或剧情专用美术资源。

独立美术资源清单需要合并：

- 已匹配 S01-S64 独立母版的 Part B UI 行与 Part E 美术/音频/技术资源行；
- 条件触发时的剧情制作通用资源行；
- 系统 ID、系统名称、资源序号、来源类型、制作状态和验收要求。

CSV 使用 UTF-8 BOM，保证 Excel 直接打开中文不乱码。
