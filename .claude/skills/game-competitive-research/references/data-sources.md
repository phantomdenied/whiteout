# 总览数据源路由

本文件只规定总览事实的采集路径。供应商能力会变化，采集时必须联网确认当前接口。

## 获取顺序与边界

1. 免费官方 API 和官方公开商店/游戏页。
2. 允许访问的第三方公开页面或 API。
3. 公开摘录和供应商报告。
4. 用户授权的付费 API 或导出文件。

不得绕过认证、付费墙、反爬、robots、限速或条款。无法自动访问时记录人工证据缺口，知识库不得保存凭据。

## 数据源矩阵

| 数据源 | 默认访问 | 主要用途 | 归一与注意事项 |
| --- | --- | --- | --- |
| Apple App Store Search/Lookup 与公开 Feed | 免费 API/Feed | 应用身份、发行商、类型、价格、评分/评论、发布/版本、可用榜单 | 明确国家商店；Search API 有限速；App Store Connect 仅用于授权的一方数据。 |
| Steam Web API / Steam 官方页 | 官方免费 API/页面；部分需 Key | AppID、当前在线、发行/平台/价格/商店信息、公开评论与公告 | `currentPlayers` 是 Steam 并发在线，不是 DAU；保留抓取时间。 |
| SteamDB | 第三方公开页；自动化可能受限 | 当前、24 小时、历史峰值 CCU、趋势、价格和商店信号 | 标为 `third-party-observed`，不得宣称官方 API 或绕过限制。 |
| Steam Charts | 第三方公开页；自动化可能受限 | 当前玩家、30 日均值/峰值、历史 CCU | 标为第三方观察，并记录页面日期和平台范围。 |
| SteamSpy | 第三方公开 API | 玩家数、时长等估算 | 基于样本外推，新游戏可靠性较低；标为 `modeled-estimate`，保留区间，不把玩家数当销量。 |
| Google Play 公开商店页 | 免费公开页；解析器需维护 | 包名、安装区间、评分/评论、版本/更新、IAP 范围 | 页面结构和地区/语言会变；仅使用允许的公开访问并保留商店地区。Play Console 导出需用户授权。 |
| AppMagic | 公开报告 + 授权产品/导出 | 下载/流水估算、榜单和品类信号 | 公开摘录可引用；产品数据须授权。标为模型估算并保留平台、国家、币种和日期窗。 |
| Sensor Tower | 公开报告 + 授权产品/导出 | 流水/下载、活跃、留存、评分评论和人群估算 | 核心指标为授权模型数据；只能用公开证据或用户授权导出/API，并保留范围。 |
| GameRefinery | 公开文章 + 授权产品/导出 | 功能分类、LiveOps、更新史、热门 IAP 与趋势 | 细颗粒产品数据需授权；区分观察到的功能事实和模型绩效。 |

## 平台路由

- iOS/iPadOS/macOS：解析 App Store ID，按国家商店调用 Search/Lookup，再查榜单、评分和版本；Apple 公开数据没有的估算才使用授权来源。
- Android：解析 Google Play 包名和地区页，保存安装区间、评分/评论、更新/版本、价格和展示的 IAP 范围。
- Steam：解析 AppID，先查官方当前在线，再在允许时补充 SteamDB/Steam Charts 历史 CCU 与 SteamSpy 玩家估算。
- 跨平台：只有周期、地区、单位、产品身份和用户重叠均完成对齐时才能相加。

## 指标元数据

`basic.marketMetrics[]`、`stageRevenue[]`、`dailyActiveUsers[]` 与 `basicMetrics[]` 应保留供应商/证据 ID、来源类型、访问方式、平台、商店地区、观察时间/周期、范围、报告/估算/推断状态和置信度。原始可比信号放 `marketMetrics[]`；只有确实代表流水或 DAU 的数据才能进入专用数组，Steam CCU 不得改名为 DAU。
