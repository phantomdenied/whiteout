# Whiteout

A downhill-skiing roguelike for phones: every slope is a chase, and the yeti is the clock. Inspired by SkiFree (1991); original name, art, and code.

**Status: design.** See the [design document](docs/GDD.md). No code yet. M0 (a feel prototype) is next.

This is a separate app from Spindle. It will get its own `package.json` here when code starts.
